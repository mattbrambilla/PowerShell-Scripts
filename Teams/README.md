# Microsoft Teams

Requires `MicrosoftTeams`. These scripts also connect with older `MSOnline` / `AzureADPreview` modules.

Replace `example.com` and the sample UPNs in the `param` block before running.

| Script | Purpose |
|---|---|
| `Export-TeamsAndMembers.ps1` | Export team membership for a filtered user list to `TeamsAndMembers.csv`. |
| `Export-TeamsAndSharePointMembers.ps1` | Same export, with an additional SharePoint Online connection. |
