# Windows

Local / on-premises utilities. No Microsoft 365 connection required.

| Script | Purpose |
|---|---|
| `lockComputerRemotely.ps1` | Lock a remote workstation via WMI (`LockWorkStation`). Set `$computerName`. |
| `change system language.ps1` | Read (and optionally set) Windows system locale / user language list. |
| `copy file between servers.ps1` | Copy files matching a filter from a source path to a destination path. |
| `removeDuplicateUsers.ps1` | Stub to remove a local Windows Mail / packaged-app folder used for duplicate accounts. Set the path before running. |
