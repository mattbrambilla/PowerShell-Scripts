# Windows

Local / on-premises utilities. No Microsoft 365 connection required.

| Script | Purpose |
|---|---|
| `Lock-ComputerRemotely.ps1` | Lock a remote workstation via WMI (`LockWorkStation`). Set `$computerName`. |
| `Set-SystemLanguage.ps1` | Read (and optionally set) Windows system locale / user language list. |
| `Copy-FilesBetweenServers.ps1` | Copy files matching a filter from a source path to a destination path. |
| `Remove-DuplicateMailUsers.ps1` | Stub to remove a local Windows Mail / packaged-app folder used for duplicate accounts. Set the path before running. |
