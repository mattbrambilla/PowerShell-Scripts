# Microsoft Entra ID

Requires Microsoft Graph PowerShell (`Microsoft.Graph` or `Microsoft.Graph.Authentication`).

| Script | Purpose |
|---|---|
| `MFA Get-AuthenticationMethods.ps1` | Export each user's MFA methods and default method to CSV (based on [Ali Tajran](https://www.alitajran.com/get-mfa-status-entra/)). |
| `Remove-AppPermissions.ps1` | Remove API permissions from an Entra ID application (based on [Ali Tajran](https://www.alitajran.com/remove-permissions-applications/)). |
